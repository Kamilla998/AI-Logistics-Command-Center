# AI Logistics Command Center

A responsive dark-mode front-end prototype for a US freight dispatch and logistics operations dashboard.

## Files
- `index.html` — dashboard pages and layout
- `styles.css` — dark UI styling and responsive layout
- `app.js` — sample data, navigation, filtering, CSV export, and demo load creation

## Publish with GitHub Pages
1. Open your repository: https://github.com/Kamilla998/AI-Logistics-Command-Center
2. Upload `index.html`, `styles.css`, `app.js`, and this `README.md` to the **root** of the repository.
3. Commit the changes to your main branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, then Save.
7. Wait a minute or two and open:
   https://kamilla998.github.io/AI-Logistics-Command-Center/

## Important
This version is a front-end demo. It includes illustrative logistics data and browser-only interactions. It does not connect to real trucks, drivers, load boards, external APIs, Google Sheets, Telegram, or the AI Employees agents. Do not enter confidential or real customer data.

## Next integration phase
The dashboard can later be connected to a backend/API and to the `markfulton/ai-employees` framework. Keep API keys and secrets out of GitHub Pages and browser JavaScript; use a secure backend for integrations.
